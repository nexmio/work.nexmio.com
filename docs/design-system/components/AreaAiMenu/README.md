# AreaAiMenu

The **✦ AI ▾** button at the top of an area (Projects, Tasks, Meetings, Start), with the same look as the AI button above a page (`NoteAiMenu`): ghost, in `primary`, with the Beta mark (left out when the header is narrow).

- The menu has small groups: **Do** (jobs that go into the AI queue) and **Ask** (a question that opens the chat and is sent, `askChat`).
- Each entry has a word and a hint line. An entry that cannot run here is grey, and the hint says why ("Choose a part first").
- Without an AI the menu starts with the AI-off note and every entry is grey.
- The last line says that every change is seen before it is written.
