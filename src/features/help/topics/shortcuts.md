## Keyboard shortcuts

On Mac, use **Cmd** instead of **Ctrl**.

| Shortcut                   | What it does                                       |
| -------------------------- | -------------------------------------------------- |
| **Ctrl+1 … 6**             | Start, Pages, Tasks, Projects, Meetings, Ideas     |
| **Ctrl+N**                 | new page                                           |
| **Ctrl+S**                 | save and commit the open page                      |
| **Ctrl+P**                 | quick open                                         |
| **Ctrl+Shift+F**           | search                                             |
| **Ctrl+Shift+K**           | link to a page                                     |
| **Ctrl+K**                 | AI commands for the selected text                  |
| **Ctrl+L**                 | open the AI (the box over the right side)          |
| **Ctrl+Shift+O**           | switch vault                                       |
| **Ctrl+Shift+P**           | command palette: pages, AI, actions                |
| **Ctrl+Shift+D**           | today's daily page                                 |
| **Ctrl+Shift+T**           | the task list                                      |
| **Ctrl+Shift+N**           | write down: T task, I idea                         |
| **Ctrl+Alt+N / P**         | any program, Windows helper: write down / left off |
| **Ctrl+Shift+H**           | history of the open page                           |
| **Ctrl+W**                 | close the tab                                      |
| **Ctrl+PageUp / PageDown** | previous / next tab                                |
| **Ctrl+\\**                | two pages side by side                             |
| **Ctrl+B / Ctrl+I**        | bold / italic                                      |
| **Ctrl+Alt+T**             | insert a table                                     |
| **Tab / Shift+Tab**        | move a list item or a line in / out                |
| **Ctrl+,**                 | settings                                           |
| **F1**                     | this guide                                         |
| **Esc**                    | close a window or list                             |
