A **project** is a folder in the vault root with its own scope and settings for Nexmio Work. Use it to keep one area apart, for example a customer, a course or a work stream.

## Make one

Choose **New → Project…** above the file tree. A window asks for:

- **Name**: this is also the name of the new folder. It is made at once, in the **vault root**, whatever you have selected in the tree.
- **About this project**: what Nexmio Work should know about it (what the pages are for, what its terms mean). The chat and the skills read it; the fixed commands (Fix, Rewrite, Shorten…) do not.
- **AI for this project**: use the **Main AI** (the app's AI), or choose an AI on your own computer. The window says which AI the project will use.
- **Local AI only**: the pages of this project never go to a cloud AI, even when the Main AI is one. The project then uses your **Local AI** (Settings → AI → Local AI), unless you choose another AI on your computer.

Under each project's name in Pages a line says **No plan yet · Make a plan** or **Open the plan**, so you can see at once whether a project has a plan.

A project is always a **new** folder of its own. A folder you already have cannot be turned into a project, and a project cannot be put inside a folder or another project. If the name is already used in the root (also with other upper/lower case, or by a page with that name), the window says so. To bring existing pages into a project, drag them onto it.

A project can be renamed (its folder name changes with it), but not moved into a folder.

## Where the project is

A project is **not** part of **All files**. It has its own tree under **Projects** at the top of the file panel:

- Click the project to open or fold it. Its pages and folders are listed below it.
- **+** next to the project makes a new page in it; the gear opens the project settings. You can also right-click inside the tree to make pages and folders.
- To move a page into a project, **drag it onto the project** (or onto a folder inside it). To take it out, drag it into All files.
- The filter box searches the projects too.

Links work across projects. A page outside any project can link to a page in a project with `[[Name]]`, and the other way round. A project only limits what **Nexmio Work** may read and change, not your links.

## What changes

When you work in a page inside the project, the chat and the skills read the project's text and stay inside the project folder. The bottom bar shows the project and the AI in use.
