## Link to another page

Click **Link to a page** in the toolbar, or press **Ctrl/Cmd+Shift+K**. A search opens over **all pages in the vault**, also in other folders and projects. Pick one and Nexmio Work writes the link for you.

- If you had selected a word, it stays as the text of the link: `[[Budget 2026|the budget]]`.
- If two pages have the same name, the link uses the path so it goes to the right one.
- Type a name that does not exist, and Nexmio Work offers a link to a **new page**. Clicking such a link later creates the page.

You can also type `[[` and a list of pages opens. Or drag a page from the file tree into the text.

| Link               | Means                        |
| ------------------ | ---------------------------- |
| `[[Note]]`         | link to the page called Page |
| `[[Note\|text]]`   | the same, shown as _text_    |
| `[[Note#Heading]]` | a heading in the page        |
| `[[Folder/Note]]`  | the page at that path        |

**Ctrl/Cmd+click** a link to open it.

## Index pages

Right-click a folder (or a project) and choose **Create index page**. Nexmio Work makes a page with a link to every page in the folder and its sub-folders.

- Click **Create index page** again to refresh the list. Only the list between the two hidden marker lines is rewritten, so text you added above or below stays.
- Right-click an empty part of the file tree for an index of the whole vault.

## When you rename or move a page

Nexmio Work asks whether to update the links in other pages. Say yes and nothing breaks.

## Tags

Write `#tag` anywhere in a page. When you type `#`, Nexmio Work suggests the tags you already use, most used first; press Esc or keep typing to ignore it, and nothing is added unless you choose one. In the **Outline** panel you see the tags of the open page (click one to search for it) and **+ tag** to add one. **···** → **Tags…** on a page is the other way: **Nexmio Work uses these** are Meeting, Epic and Pinned, which change what Nexmio Work does with the page (the window says what each does); **Your tags** are any words you want, one word each, and you can click a tag you already use on another page to put it on this one too. Your tags and Nexmio Work's are shown apart, and the AI never adds or takes away Nexmio Work's. In the search panel, your tags and Nexmio Work's tags are shown in two groups with their counts while the search box is empty; a click searches for it (`tag:name`). The AI button above a page has **Suggest a title and tags**.
