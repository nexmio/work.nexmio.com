## Find a page

- **Quick open** (**Ctrl/Cmd+P**): type part of a page's name and press Enter.
- **Search** (**Ctrl/Cmd+Shift+F**): searches the text of all pages while you type. The field in the middle of the top bar (**Ctrl/Cmd+P**) finds a page by name and jumps to it; its last row, **Search the text of all pages for …**, opens this search with what you typed.
- The **filter box** above the file tree narrows the tree to matching names.

## Search tips

| Type               | Finds                                            |
| ------------------ | ------------------------------------------------ |
| `firewall`         | pages with the word (and words starting with it) |
| `tag:security`     | pages with the tag `#security`                   |
| `path:Work`        | only pages in the folder Work                    |
| `tag:iso password` | a tag and a word together                        |

## Search by meaning

If you have turned on **Semantic search** in **Settings → AI**, the search panel shows **Keyword**, **Meaning** and **Both**. _Meaning_ finds pages that talk about the same thing even with different words. _Both_ combines them.

It only uses an embedding model on your own computer, so no page is sent to a cloud service.
