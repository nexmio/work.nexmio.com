# Nexmio brand kit

Generated copy of the shared Nexmio brand. **Do not edit these files here.**
Change them in the Nexmio control repo and run the export script again.

- Brand version: `5e5a000`
- Exported: 2026-11-15
- Colours included: purple, yellow
- App material (icon sizes, app/desktop backgrounds): yes

## What is in here
- `LAYOUT.md`: the layout every Nexmio site follows.
- `preview/brand.css`: colour tokens and shared components.
- `preview/img/<colour>/`: N mark, favicon, banner and site backgrounds (with app material: icon sizes, `app-bg-*` and `desktop-bg-*`).
- `preview/site/`: the layout PoC pages (reference only; build the real site from them).

Everything outside this `brand/` folder belongs to the product and is never touched by the export.
